# StudentHub - Student Management System

## Project Overview
StudentHub is a responsive web-based Student
Management System developed as part of my
Web Development Internship at Codec Technologies
Pvt. Ltd.

The system helps users manage student records
efficiently through a simple and interactive
dashboard.

## Live Demo
https://ansumanmistry9-hash.github.io/Studenthub/

## Features
- Interactive dashboard
- Add new students
- Edit student information
- Delete student records
- Search student records
- Automatic grade calculation
- Pass and fail status
- Average marks calculation
- Responsive web design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- GitHub
- GitHub Pages

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Start managing student records.
